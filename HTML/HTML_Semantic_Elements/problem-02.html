Life at TechNova

Open Positions

Software Engineer

Design, develop and maintain scalable software applications. Candidates should have strong programming and problem-solving skills.

Skills: C++, Java, Python, Git and SQL

Frontend Developer

Build responsive and accessible web interfaces using modern frontend technologies.

Skills: HTML, CSS, JavaScript and React

Backend Developer

Develop secure APIs and scalable backend services for TechNova products.

Skills: Java, Python, Node.js and databases

Data Analyst

Analyze business data and create reports that help teams make informed decisions.

Skills: SQL, Excel, Python and data visualization

UI/UX Designer

Create intuitive user experiences and attractive interfaces for web and mobile applications.

Skills: Figma, wireframing and prototyping

Cloud Engineer

Manage cloud infrastructure and develop reliable, scalable deployment systems.

Skills: AWS, Docker, Linux and Kubernetes

Cybersecurity Analyst

Monitor systems, identify security risks and help protect company applications and infrastructure.

Skills: Networking, Linux, security tools and SIEM

Example Technical Skill Stack

Frontend : HTML5 | CSS | JavaScript | React
Backend  : Node.js | Python | Java
Database : MySQL | PostgreSQL | MongoDB
Cloud    : AWS | Docker | Kubernetes
Tools    : Git | GitHub | VS Code

Candidates are not required to know every technology listed above. Skills vary according to the position.
